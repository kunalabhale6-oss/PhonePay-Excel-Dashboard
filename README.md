# PhonePe Transaction Analysis Dashboard

This project is an Excel-based data analysis and visualization project using PhonePe transaction data. The objective of the project is to explore transaction patterns, identify trends, and present key insights through an interactive and visually organized dashboard.

### Tools & Features

* Microsoft Excel
* Data Cleaning & Preparation
* Pivot Tables
* Pivot Charts
* Data Visualization
* Interactive Dashboard
* Transaction Trend Analysis
* Category-wise and time-based analysis

### Project Highlights

The dashboard provides a summarized view of the available PhonePe transaction data and helps analyze important patterns such as transaction volume, transaction values, payment categories, and trends over time.

This project demonstrates practical skills in **Excel, data analysis, visualization, and dashboard creation**.
